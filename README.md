# 🗺️ SHOHIN TAJIKISTAN (SHOHIN GO)

Современный мобильный веб-путеводитель и интерактивная карта Душанбе. Проект создан для быстрого поиска мест, категорий, транспорта и услуг в столице Таджикистана.

## 🚀 Особенности проекта
- **Интерактивная карта** на базе Leaflet с метками и определением геолокации (GPS).
- **Категории мест:** рестораны, кафе, магазины, аптеки, отели, авто и многое другое.
- **Транспорт Душанбе:** актуальные автобусные маршруты и колл-центры такси.
- **Интерфейс под мобильные устройства** с поддержкой темной темы и мультиязычности.
- **Возможность добавления бизнеса** пользователями через встроенную форму заявки.

## 🛠️ Технологии
- **HTML5 / CSS3 / JavaScript (Vanilla)** — чистый код без тяжелых фреймворков для максимальной скорости работы на любом смартфоне.
- **Leaflet.js** — для отрисовки интерактивных карт.
- **GitHub Pages** — для быстрого хостинга и развертывания.
