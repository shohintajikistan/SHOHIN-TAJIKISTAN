# SHOHIN — приложение поставщиков и заказов

Мобильное приложение для продуктового магазина в Таджикистане: отдельные карточки поставщиков, их профили и каталоги, корзина и отправка заказа конкретному поставщику через WhatsApp.

## Возможности
- Добавление, изменение и удаление поставщиков (имя, телефон, категории товаров).
- Отдельный каталог каждого поставщика.
- Товары с фото, названием, ценой в сомони и описанием; добавление, изменение и удаление.
- Корзина с количеством, подсчётом суммы и отдельным заказом выбранному поставщику.
- Формирование сообщения и переход в WhatsApp по номеру поставщика.
- История заказов.
- Локальное хранение данных на устройстве, экспорт и импорт резервной копии.
- PWA Service Worker: после первого открытия веб-версия кеширует оболочку приложения и открывается без сети.
- Android-версия собирается через Capacitor.

## Проверка веб-версии
Для проверки офлайн-режима приложение нужно открыть по HTTPS (например, через GitHub Pages) и хотя бы один раз загрузить онлайн. Service Worker не работает при открытии файла напрямую через `file://`.
Откройте `index.html` для обычного локального просмотра либо разверните папку на HTTPS-хостинге. Данные хранятся отдельно в браузере каждого устройства.

## Сборка Android APK
```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```
APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions автоматически собирает debug APK при изменениях в `supplier-app/**`. Готовый файл доступен в разделе Actions → успешный запуск → Artifacts → SHOHIN-debug-APK.

## Важно
Офлайн доступны приложение и сохранённые локально данные. Для отправки заказа через WhatsApp интернет и установленный WhatsApp (или WhatsApp Web) необходимы. Данные пока не синхронизируются между разными телефонами.
