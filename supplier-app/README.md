# SHOHIN — приложение поставщиков и заказов

Мобильное приложение для магазина: контакты поставщиков, их каталоги, корзина и отправка заказа в WhatsApp.

## Уже реализовано в MVP
- Добавление, изменение и удаление поставщиков.
- Имя, телефон и описание категорий товаров поставщика.
- Каталог товаров: название, цена в сомони, фото и описание.
- Корзина с изменением количества и автоматическим подсчётом суммы.
- Формирование текста заказа и открытие WhatsApp по номеру поставщика.
- История сформированных заказов.
- Локальное сохранение данных на устройстве.
- Экспорт и импорт резервной копии данных.

## Запуск веб-версии локально
Откройте `index.html` в браузере. Для удобной проверки на телефоне можно развернуть папку `supplier-app` на статическом хостинге.

## Сборка Android APK
В папке проекта:
```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

APK после успешной сборки:
`android/app/build/outputs/apk/debug/app-debug.apk`

В репозитории настроен GitHub Actions workflow `.github/workflows/build-android-apk.yml`, который запускается при изменениях в `supplier-app/**` или вручную через Actions. APK публикуется как workflow artifact.

## Важное ограничение текущего MVP
Данные сейчас хранятся локально на одном устройстве браузера/приложения. Синхронизация между несколькими телефонами, учётные записи сотрудников, облачная база и серверная панель администратора — следующие этапы разработки.
